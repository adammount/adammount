### Проекты

**[Save Food](https://save-foods.com)** · [Репозиторий](https://github.com/adammount/save-food-case) · [Кейс](https://adammount.org/projects/save-food)  
Маркетплейс еды, которую магазины иначе выбросили бы. Гео-поиск на PostGIS, резервирование остатков, которое переживает два одновременных «купить», выдача по QR, WebAuthn, YooKassa.

**[The Club](https://aidaclub.ru)** · [Кейс](https://adammount.org/projects/the-club)  
E-commerce премиальной косметики. Два сервиса в одном монорепозитории, синхронизация с Bitrix24, CDEK и складом Celicom по крону. Код клиентский, остаётся закрытым.

**[Detal](https://muraauto.ru)** · [Репозиторий](https://github.com/adammount/auto-shop) · [Кейс](https://adammount.org/projects/detal)  
Каталог автозапчастей. Фасетный поиск, оптовые цены на уровне полей, пересчёт суммы заказа на сервере, чтобы клиент не спорил. Payload CMS с ISR.

**[Adamix](https://adamics.uk)** · [Репозиторий](https://github.com/adammount/adamix) · [Кейс](https://adammount.org/projects/adamix)  
Свой магазин, сделанный целиком. NestJS, PostgreSQL, OAuth, загрузка медиа.

**[Closetly](https://github.com/adammount/closetly-case)** · [Кейс](https://adammount.org/projects/closetly-case)  
Приложение на React Native поверх API на NestJS и Redis.
